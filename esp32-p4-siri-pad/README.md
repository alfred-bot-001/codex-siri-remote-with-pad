# Siri Voice Pad · ESP32-P4 5 寸横屏移植

目标硬件：Waveshare ESP32-P4-WIFI6-Touch-LCD-5。当前阶段包括**可交互浏览器原型**和已刷入新板的**横屏界面测试固件**；旧 ESP32-S3 固件与其配对数据未改动。测试固件只验证显示、触控、页面和本板按键映射保存，蓝牙、USB 键盘及麦克风尚未接入。

打开 [`design/index.html`](design/index.html) 可以查看 1280×720 横屏原型。原型中的搜索、连接、断开、移除配对和按键反馈是模拟状态，不会操作真实蓝牙或向电脑发送键盘输入。实机测试版源码及刷写边界见 [`firmware/README.md`](firmware/README.md)：板上蓝牙页明确显示“未连接／驱动未接入”，不会显示模拟的已连接状态。

## 主界面

- 左侧保留 ChatGPT／Claude 唤起隐藏按钮及输入法切换；中部为板载麦克风点按开关和语音状态；右侧放大左箭头、右箭头、回车、空格按钮。
- 顶栏分别显示电脑 USB 连接和 Apple TV 遥控器蓝牙状态。点按蓝牙状态直接打开设置页的蓝牙分区，点“设置”进入完整设置页。
- 遥控器映射保持现有行为：圆环左／右为 ChatGPT／Claude；中央为回车；播放暂停为空格；减号／加号为左／右箭头；小电视为输入法切换；按住语音键为右 Option 加遥控器麦克风。点按屏幕麦克风使用板载麦克风，再点停止。
- 高亮的应用按钮只代表最近由 Pad 发出的快捷键，不能代表电脑实际前台状态。

## 蓝牙连接设置

1. 展示已配对设备及其连接状态，提供重新连接、断开、移除配对；移除需要二次确认。
2. “搜索设备”列出具有 HID 服务且符合 Apple TV 遥控器广播特征的候选设备。用户选中后连接并配对，成功后将身份保存到 NVS；下次开机自动重连。
3. 搜索超时、配对失败、断连、重连中必须分别显示实际状态。断连时立即释放 HID 按键和右 Option，结束语音。
4. 遥控器麦克风与板载麦克风互斥；切换应用／输入法时先释放语音修饰键。

## 按键映射设置

- 设置页列出圆环左右、上下、中央确认、播放暂停、音量加减、小电视、语音、返回、静音和电源键；未使用的键默认“未设置”。
- 点“编辑”可设置为单键／组合快捷键、遥控器语音键（左／右 Option），或不执行动作。组合快捷键在触屏上选择 Control、Option、Command、Shift 和主键；无需连接实体键盘输入配置。
- 每项保存后，浏览器原型会更新主页快捷键说明，并用 `localStorage` 保留设置；可恢复默认或导出 JSON。原型的保存**只在当前浏览器生效**。板上测试固件另将映射写入 P4 NVS 并在重启后读取，但尚未接入真实 BLE／USB 按键发送流程；后续需实现按下／释放和断连释放。
- 已用 Chromium 验证原型中的映射保存、重新加载、恢复默认，以及蓝牙搜索、选择、连接流程；这些检查只验证交互状态，不代表板载 BLE 已通。

## 硬件移植边界

此板的 ESP32-P4 没有内置蓝牙。BLE 来自板载 ESP32-C6，经 SDIO/ESP-Hosted 与 P4 通信；需要先在**实物**上验证 C6 固件与 P4 主机的 BLE 扫描、连接、配对、通知和断连恢复。旧 S3 上的 NimBLE 初始化不能直接复制。厂家示例只给出 Wi-Fi 主机兼容范围，没有标定本板 C6 从机固件与 BLE 中心设备组合。遥控器麦克风数据量较高，连接间隔和连续收包还需实测。

2026-09-29 已从新接入的 `/dev/cu.usbmodem5B901242401` 串口只读观察到 `ESP-ROM:esp32p4-eco7-20260109`，可与旧 S3 Pad 的 `1020BA4658B4-PAD1` 串口区分；尚未探测 Flash、改动配对或烧录。

屏幕为 HX8394 720×1280 MIPI-DSI；横屏使用 1280×720 旋转和对应 GT911 触控坐标。板载双麦克风由 ES7210 输入，与旧板 ES8311 单麦克风路径不同。电脑键盘和 USB 麦克风应接板上 **USB OTG** 口；**USB TO UART** 口用于供电、烧录和日志。两口不要混淆。

厂商 ESP-IDF 示例 `08_lvgl_demo_v9` 使用官方 LCD5 BSP `^1.0.4`、HX8394 `^2.1.0` 和 LVGL 9.5。移植工程应以此初始化 DSI/GT911，而旧工程基于 ST7796/FT6336/LVGL 8。待识别新板实际芯片 revision 后，按厂家 `rev3_x` 或 `rev1_3` 配置分别构建，不根据产品型号猜测硅片版本。不得将旧板固件刷到 P4。
